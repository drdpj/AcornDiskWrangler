## Acorn Disk Wrangler 1.5.0

The program now shares its code with CP/M Disk Wrangler, in the DiskWranglerCore library (version 1.1.0). Most of
that can't be seen from outside; what can is below.

### New
- **Command-line program `acorndw`.** Installed beside the program (Windows: beside the `.exe`; macOS: inside the app,
  `Contents/MacOS/acorndw`; Linux: `/usr/bin/acorndw` from the `.deb`, or the AppImage started under the name
  `acorndw`). It lists, extracts, adds, removes, renames and changes files on any disc the program opens, makes new
  discs and converts between kinds of image, with `--json` output, exit codes and `--dry-run`. See "Command line" in
  the README.
- **More kinds of image file.** Acorn discs stored in ImageDisk (`.imd`), DSK and extended DSK (`.dsk`) files open
  like plain sector dumps and save back in the same kind of file; TeleDisk (`.td0`) files can be read.
- **Save As writes more kinds of image.** File > Save As on a floppy (ADFS, DFS, DOS Plus, PC) can write an ImageDisk,
  DSK, extended DSK or raw image, whatever the disc was opened as; the file type chosen in the dialog decides the
  kind, not the name you type. The window and `acorndw convert` write exactly the same bytes. A TeleDisk image can now
  be saved as a writable kind. A hard disc still saves a copy of its own kind.
- **CP/M discs open in CP/M Disk Wrangler.** Opening a CP/M disc starts CP/M Disk Wrangler with it, if it is
  installed, and says so. If it can't be found, the message has a **Locate...** button: show the program once and it
  is remembered.
- **A question when a disc could be read two ways.** If two filesystems fit a disc equally well, the program asks
  which to use.
- **Tools > DFS directories become ADFS directories** (on by default). Copying DFS files onto an ADFS disc puts each
  directory letter's files in an ADFS subdirectory of that name (as before), keeping the letter's case and reusing a
  subdirectory of either case; turned off, they all go in the target directory. A letter ADFS can't have becomes
  `X_NAME`. Host files whose `.inf` names `D.NAME` follow the same rule, so DFS -> host -> ADFS gives the same result
  as DFS -> ADFS.

### Changed
- **Safer saving.** A save now writes a complete new copy of the image beside it, opens and checks that copy, and only
  then puts it in place of the old file, so a failed or interrupted save never leaves a half-written image. It needs
  free space for the second copy, a large hard disc image takes a second or two longer, and on Windows the save is
  refused (and nothing changed) while another program, such as an emulator, has the image open.
- **Folders are read the same way everywhere.** Adding or dropping a folder, and `acorndw put`, read it alike: folders
  first, then files, in name order ignoring case; linked files and folders inside a folder are skipped (a file or
  folder you name yourself is read as before). A file that can't be read is reported and the rest are still added.
- **A DFS disc's title is kept exactly as it was.** Other changes to a DFS disc (adding, deleting or renaming a file,
  the boot option) now leave the disc's title as it is on the disc, as DFS itself does; before, a title padded with
  spaces was written back padded with zeros. Setting the title (Rename disc, `acorndw title`) works as before.

### Fixed
- **Dragging files out on Linux.** Files dragged out onto GNOME Files (Nautilus), a terminal or another program now
  arrive on Linux under X11 and on a GNOME Wayland session; before, GNOME Files (and, on Wayland, every other
  program) got nothing. "Dragged out" now appears once the files have been asked for and written, and when a drag let
  go outside the program copied nothing (the drop was refused or cancelled, or no file was asked for) the status bar
  says "Nothing was dragged out".

### Known limits
- Watford's double-density DDFS, ADFS new-map discs (D and E) and copy-protected discs aren't supported.
- TeleDisk images can't be saved as TeleDisk (Save As writes another kind).
- Discs written by this version have been checked against Watford's ROM code, but not yet read by it on a real
  machine.
- A new DOS Plus 640K disc hasn't yet been tried on a real Master 512.
- None of the builds is signed: Windows and macOS warn the first time (see the README).

### Building from source
The shared code is the DiskWranglerCore library (version 1.1.0), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release.

### Downloads
Windows installer and zip, macOS disk image, Linux AppImage and .deb, each for Qt 6, with `acorndw` in each; and
the complete source (`...-source.tar.gz`, with `core/`).
