## Acorn Disk Wrangler 1.6.2

A manual page for `acorndw`. It moves to the DiskWranglerCore library version 1.5.0 (from 1.4.2). Nothing changes in
how the program reads or writes discs and tapes.

### New
- **A manual page for `acorndw`.** The Linux `.deb` installs it, so `man acorndw` describes every command and option,
  with examples. `acorndw COMMAND --help` now lists that command's options.

### Known limits
- As in 1.6.1: tapes recorded as sound (WAV, CSW) and the Acorn Atom's aren't read; ZX Spectrum and Amstrad CPC tapes
  (TZX, CDT, TAP) are named, not opened; the Electron's OS hasn't been checked against the BBC's; tapes written here
  were checked in an emulator, not on a real cassette recorder; `acorndw` has no command to change the order of a
  tape's files (the window does it); Watford's double-density DDFS, ADFS new-map discs (D and E) and copy-protected
  discs aren't supported; TeleDisk images can't be saved as TeleDisk; discs written by this program have been checked
  against Watford's ROM code but not yet read by it on a real machine; a new DOS Plus 640K disc hasn't yet been tried
  on a real Master 512; none of the builds is signed.

### Building from source
The shared code is the DiskWranglerCore library (version 1.5.0), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release. For 32-bit
Windows (Windows 7 SP1 and later), see `core/docs/building-windows-32bit.md`.

### Downloads
