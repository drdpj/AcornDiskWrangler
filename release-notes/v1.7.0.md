## Acorn Disk Wrangler 1.7.0

Acorn Atom discs, and the Atom's files from the computer. It moves to the DiskWranglerCore library version 1.6.0
(from 1.5.0).

### New
- **Acorn Atom DOS discs** (`.ssd`, `.dsd`; 40 or 80 track, single- or double-sided) open and can be changed as the
  Atom's own DOS changes them: files in its default directory are listed by name, load and exec addresses are 16 bits,
  there is no boot option, and the catalogue is written as the Atom writes it (checked against the Atom DOS ROM and a
  real disc from an Acorn System). A disc with a file in the Atom's default directory is recognised by itself. A blank
  Atom disc looks exactly like a blank DFS disc, so Tools > *Read as Acorn Atom DOS* reads one as Atom DOS (nothing is
  written), and File > New disc image has Atom presets (40 and 80 track, single- and double-sided) that open that
  way. `acorndw --fs=atom` does the same. Files copied between Atom, BBC DFS and ADFS discs keep their place: the
  Atom's default directory is DFS's `$`, and a BBC address such as `FF1900` arrives on the Atom as `1900`.
- **Atom files from the computer.** `.atm` files (as MAME and the Atom software archives keep them) are read by their
  header: name, load and exec. AtomInPC files (a 16-byte header) are read by theirs when they go onto an Atom disc and
  Tools > *Read AtomInPC headers when adding to an Atom disc* is on (`acorndw put --atominpc`). Files copied off an
  Atom disc get `.inf` files, as DFS files do.
- The manual page (`man acorndw`) is easier to read: no stretched spaces between words, and a comment above every
  example.

### Known limits
- Atom discs written by this program have been checked against the Atom DOS ROM's code, not yet read by a real Atom or
  an Atom emulator. Copying files off an Atom disc as AtomInPC or `.atm` files isn't offered yet (they get `.inf`
  files).
- As in 1.6.2: tapes recorded as sound (WAV, CSW) and the Acorn Atom's tapes aren't read; ZX Spectrum and Amstrad CPC
  tapes (TZX, CDT, TAP) are named, not opened; the Electron's OS hasn't been checked against the BBC's; tapes written
  here were checked in an emulator, not on a real cassette recorder; `acorndw` has no command to change the order of
  a tape's files (the window does it); Watford's double-density DDFS, ADFS new-map discs (D and E) and copy-protected
  discs aren't supported; TeleDisk images can't be saved as TeleDisk; discs written by this program have been checked
  against Watford's ROM code but not yet read by it on a real machine; a new DOS Plus 640K disc hasn't yet been tried
  on a real Master 512; none of the builds is signed.

### Building from source
The shared code is the DiskWranglerCore library (version 1.6.0), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release. For 32-bit
Windows (Windows 7 SP1 and later), see `core/docs/building-windows-32bit.md`.

### Downloads
Windows installer and zip, macOS disk image, Linux AppImage and .deb, each for Qt 6, with `acorndw` in each (and its
