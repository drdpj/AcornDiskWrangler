## Acorn Disk Wrangler 1.6.1

A fix to writing cassette tapes. It uses the DiskWranglerCore library version 1.4.2 (the same code as 1.4.1; its
32-bit Windows building notes now cover all three programs).

### Fixed
- **A name already on a tape is no clash.** A tape can hold any number of files of one name, but a file dropped on
  a tape that already had one of its name was only offered as a replacement. Now a file dropped, added or pasted onto
  a tape goes on its end whatever its name. Only a file identical to one already on the tape (the same name, load and
  exec addresses and contents) is asked about: **Add another copy?** (Yes, Yes to all, No to skip it, No to all,
  Cancel). Discs are unchanged: a name already there is asked about as before.
- **`acorndw`** does the same: `put` and `copy` onto a tape add a file whose name is already there. An identical file
  is still a clash (exit 5; `--skip` skips it), and `--replace` replaces the first file of that name.

### Known limits
- Tapes recorded as sound (WAV, CSW) and the Acorn Atom's aren't read; ZX Spectrum and Amstrad CPC tapes (TZX, CDT,
  TAP) are named, not opened.
- The Electron's OS hasn't been checked against the BBC's (the Electron tapes tried read the same). Tapes written
  here were checked in an emulator, not on a real cassette recorder.
- `acorndw` has no command to change the order of a tape's files (the window does it).
- Watford's double-density DDFS, ADFS new-map discs (D and E) and copy-protected discs aren't supported.
- TeleDisk images can't be saved as TeleDisk (Save As writes another kind).
- Discs written by this program have been checked against Watford's ROM code, but not yet read by it on a real
  machine.
- A new DOS Plus 640K disc hasn't yet been tried on a real Master 512.
- None of the builds is signed: Windows and macOS warn the first time (see the README).

### Building from source
The shared code is the DiskWranglerCore library (version 1.4.2), a git submodule in `core/`. Clone with
`git clone --recurse-submodules`, or run `git submodule update --init` after cloning. GitHub's "Download ZIP" and
"Source code" archives leave `core/` empty; use the complete source archive attached to this release. For 32-bit
Windows (Windows 7 SP1 and later), see `core/docs/building-windows-32bit.md`.

### Downloads
Windows installer and zip, macOS disk image, Linux AppImage and .deb, each for Qt 6, with `acorndw` in each; and
the complete source (`...-source.tar.gz`, with `core/`).
