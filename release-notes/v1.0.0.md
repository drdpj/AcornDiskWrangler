## Acorn Disk Wrangler 1.0.0

The first stable release. Acorn Disk Wrangler views and edits disc images from the BBC Micro, Master and Master
512: ADFS hard discs (BeebSCSI `scsi0.dat` and the DOS Plus partition inside one) and floppies, DFS `.ssd` / `.dsd`,
Acorn DOS Plus 800K and 640K discs, and PC floppies. Files can be added, extracted, renamed, deleted and copied
between discs, dragged to and from the desktop, and exchanged with CP/M Disk Wrangler and other tools through the
open [retro-files](https://github.com/drdpj/AcornDiskWrangler/blob/main/docs/retro-files-format.md) format.

### Since 1.0.0 release candidate 2
- The Open dialog now lists upper-case extensions too (`GAME.SSD`, `DISC.ADL`); Linux file dialogs match
  case-sensitively and were hiding them.
- Help > Licences shows the third-party notices formatted, as the Markdown they are.
- Linux: the AppImage has its icon at the top of the AppDir, the `.deb` ships the standard licence texts its
  packages' copyright files point to, and on a GNOME Wayland session the program no longer prints "Ignoring
  WAYLAND_DISPLAY on Gnome" when started from a terminal.
- macOS builds are made on macOS 15 (GitHub retired the macOS 14 runners).
- The retro-files specification now says that CP/M names are never converted.
- For developers: the sources have moved into `src/`, and AGENTS.md is split, with the disc format notes in
  `docs/disc-formats.md` and the tests in `docs/testing.md`.

### Known limits
- ADFS new-map discs (D and E), Watford's 62-file DFS and copy-protected discs aren't supported.
- A new DOS Plus 640K disc hasn't yet been tried on a real Master 512.
- None of the builds is signed: Windows and macOS warn the first time (see the README).
