## Acorn Disk Wrangler 1.1.0

### New: Watford DFS 62-file discs
- Discs with Watford Electronics' 62-file catalogue (`.ssd`, or either side of a `.dsd`) are recognised. All their
  files are listed, and files can be added, extracted, renamed, deleted and copied as on any DFS disc, up to 62 per
  side. Before, only the first 31 files were shown, and saving could overwrite the second catalogue.
- File > New disc image can make blank 62-file discs: single- or double-sided, 40 or 80 track.
- The status bar and Tools > Check disc say when a side has a 62-file catalogue.
- Writes follow Watford's own DFS 1.44 / DDFS 1.54T. A new file goes where Watford would put it, and files stay
  in their own catalogue. The first catalogue's disc size is lowered so that Acorn DFS can't write over the
  files in the second. A `!.!!!!!!!` guard entry written by some tools is kept but not listed.

### Known limits
- Watford's double-density DDFS, ADFS new-map discs (D and E) and copy-protected discs aren't supported.
- Discs written by this version have been checked against Watford's ROM code, but not yet read by it on a real
  machine.
- A new DOS Plus 640K disc hasn't yet been tried on a real Master 512.
- None of the builds is signed: Windows and macOS warn the first time (see the README).
